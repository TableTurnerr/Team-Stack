Pricing sources (verified 2026-04)
  • Apify Google Maps Scraper: Scraped place — Free $4.00/1k, Starter $4.00/1k, Scale $3.00/1k, Business $2.10/1k. Add-ons (paid tier): additional details $1.05/1k, company contacts $1.05/1k, email verify $2/1k, social $6/1k. Free-tier add-ons: email/social $100/1k (huge gotcha).
  • Apify subscription: Starter $29/mo with $29 platform credit included — credit covers Actor compute but you still pay add-on results. Free plan has $5 credit.
  • Google Places API (New): Nearby Search $32/1k (5k free/mo). Place Details: Essentials $5/1k (10k free), Pro $17/1k (5k free), Enterprise $20/1k (1k free).
  • Free tiers stack: The free monthly Places quota is applied first in calculations — small volumes can be effectively free.
  • Hybrid logic: Nearby Search returns name/rating/types/place_id cheaply → filter on those fields free → call Place Details only on candidates passing pre-filter → use the script/extension for fields Google won't expose (emails, deep socials, menu signals).
  • Not modeled: Claude API tokens (assumed $0, no Claude in production loop), one-time dev cost, anti-bot incidents.
